# Toy Operating System Kernel Simulator

Demonstrates the foundational components of an operating system kernel without cutting architectural corners. Implements process control blocks (PCBs), preemptive round-robin CPU scheduling, page table address translation with page-fault detection, and privileged system call traps.

## Language

`python`

## How to Run

Run the script with standard Python 3:
python main.py
